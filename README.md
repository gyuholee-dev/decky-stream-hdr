# StreamHDR

StreamHDR은 Steam Remote Play에 BT.2020 PQ HDR 스트리밍을 지원하는 데키 플러그인입니다. 스팀OS 및 포크와 스팀 게임모드가 설치된 리눅스 기기가 HDR 스트리밍이 가능한 사양일 경우, 이 플러그인을 통해 스팀의 스트리밍 과정에 개입하여 호스트에 대한 HDR 인코딩 요청을 수정하고 클라이언트의 HDR 렌더링 출력을 가능하게 설정할 수 있습니다.

## 사용 방법

1. 플러그인 메뉴에서 HDR Streaming을 켠 뒤 Remote Play를 실행하십시오. 이미 실행 중이라면 스트리밍을 종료한 뒤 다시 실행해야 적용됩니다.
2. Paper White는 HDR 스트리밍이 어느 정도의 밝기로 출력될지 결정하는 기준값입니다. 이 값을 변경하고자 할 경우 스트리밍을 종료해 주십시오.
3. Contrast, Gamma, Saturation은 HDR 출력 이미지를 사용자의 선호에 맞게 조정할 수 있는 설정입니다. 이 값들은 스트리밍 중에도 자유롭게 변경할 수 있습니다.
4. 플러그인의 모든 설정은 Remote Play에만 적용되며, 이 기기에서 직접 실행되는 게임에는 영향이 없습니다.

## 요구사양

- 호스트 PC(게임을 실행하는 PC): HDR 지원 게임 및 HDR 모니터와, HDR 게임을 직접 원활하게 실행 가능한 사양의 PC가 필요합니다. 확인된 환경은 Windows 11, RTX 50, 삼성 OLED 모니터입니다.
- 클라이언트(이 기기): HDR 디스플레이가 내장되거나 또는 외장으로 연결된 기기에서 스팀OS를 게임 모드로 실행해야 합니다. 확인된 환경은 Lenovo Legion Go 2 OLED와 CachyOS Handheld입니다.
- 네트워크: 고대역폭 저지연 네트워크 환경을 권장합니다. 2.5GbE 유선 환경 및 5GHz Wi-Fi 환경에서 테스트했습니다.
- 스팀에 2026년 10월부터 추가된 PyroWave 동영상 옵션을 필수로 사용해야 합니다. (NVFBC 캡처는 반드시 꺼 주십시오)

## 호스트 설정

- 호스트 PC > Steam 설정 > Remote Play > 고급 호스트 설정
- 고급 호스트 옵션 사용: 켬
- 스트리밍 시 기본 디스플레이: HDR 디스플레이
- 스트리밍 디스플레이 HDR: 기본 또는 맞춤 설정 (HDR 사용: 켬)
- NVIDIA GPU에서 NVFBC 캡처 사용: 끔
- 하드웨어 인코딩 사용: 켬
- 네트워크 트래픽 우선순위 조정: 켬

## 클라이언트 설정

- 이 기기의 Steam 설정 > Remote Play > 고급 클라이언트 설정
- 고급 클라이언트 옵션 사용: 켬
- 동영상: 품질 우선
- 대역폭 제한: 무제한
- 해상도 제한: 이 기기의 해상도
- 프레임 속도 제한: 이 기기의 주사율
- HDR: 사용
- 하드웨어 디코딩: 켬
- HEVC 동영상: 켬
- AV1 동영상: 끔
- PyroWave 동영상: 켬 (품질 조정 1 이상)
- 낮은 지연 시간 네트워크: 켬
- 이 기기의 Steam 설정 > 개발자 > HDR 호환성 테스트: 켬
